# Task 2: Data Visualization and Storytelling

## Project Overview

This project focuses on analyzing Superstore sales data using Microsoft Power BI to identify business trends and insights through interactive visualizations.

## Tools Used

* Microsoft Power BI
* Superstore Dataset
* GitHub

## Dashboard Components

* Total Sales
* Total Profit
* Total Orders
* Monthly Sales Trend
* Sales by Category
* Profit by Region

## Key Insights

* Technology is the highest-selling category in the dashboard.
* The West region generates the highest profit.
* Monthly sales trends help identify changes in business performance.
* KPI cards provide a quick overview of overall sales and profitability.

## Deliverables

* Power BI Dashboard (.pbix)
* Dataset (.csv)
* Dashboard Screenshot (.png)

## Conclusion

This project demonstrates how data visualization can transform raw sales data into meaningful business insights and support data-driven decision-making.
